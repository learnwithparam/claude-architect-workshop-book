      Confidence routing

      Check confidence against labels before it routes anything

      The refund desk auto-approves every field Claude rates as confident. Scanned forms carry misread digits, and Claude rates them as high as clean ones. Wrong refunds go out with nobody looking. This is the refund desk at Lumen Supply. You will watch confidence route wrong rows, then fix the router so it trusts a form type only after it is measured against labels.

      The router decides who reviews each row

      Forms arrive typed and scanned. Claude reads each one and rates its own confidence. A router then decides which rows are approved and which go to a human.

      The router sees a labelled set: rows where the right amount is known. That is the only way to learn which confidence to trust.

      Measure each form type, then route on the measurement

      A row is also held when it has no amount or a confidence below a floor of 0.5, even in a proven type. A missing read is never approved.

      Three changes, made in this order in route.py. The report gives accuracy per form type from the labelled rows. A row is approved only when its type has met the target and the row has an amount and some confidence. An unmeasured type is held.

      A stratified sample of the approved rows is also checked: a random draw from every type, so a type that drifts is noticed.

      What goes to a human

      Switch between the two routers on the scanned queue. A weak type, an unmeasured type and a row with no amount all go to a human. A field whose source is unclear, such as a faded digit, goes to a human with the scan attached.

      The router holds a row for a reason it can name, and never because Claude sounded unsure.

      When two forms give different totals for one order, keep both values, each with the form it came from. Pass every value on with its source and the date it was read, so the next reader can check it.

      Check your understanding

      Answer each question, then read why every option is right or wrong. The wrong options are the mistakes engineers make on the job.

      1. A refund router shows 97% accuracy over 900 forms a day, but scanned forms are right 61% of the time. What report would have shown this?

      1. AOne accuracy figure over the whole day, recomputed every hour.
      2. BThe average confidence Claude wrote on each form.
      3. CAccuracy for each form type, measured against human labels.
      4. DA count of how many forms a human reviewed.
      Show the answer

      Answer: C

      • A A fresher average still blends the typed forms with the scans, so the weak type stays hidden.
      • B Confidence is what Claude wrote about its own reading. It is not a check against the paper.
      • C Correct. A per-type figure separates the 61% from the 97%.
      • D Review counts say how busy people were, not how often a type is wrong.

      2. A router approves any form with a confidence of 0.9 or more. Nobody has compared that number with the true amounts. What should the team do first?

      1. AScore a labelled set and learn how often each confidence level is right.
      2. BAsk Claude to explain how it chooses its confidence numbers.
      3. CRaise the bar to 0.95, since a higher number is a safer number.
      4. DSend every form to a human until the model improves.
      Show the answer

      Answer: A

      • A Correct. Labels are the only way to learn what a confidence level is worth.
      • B Claude can describe its number, but the description is not a measurement of how often it is right.
      • C A higher bar on an unchecked number is still a guess, and scans may score high anyway.
      • D This works, but it gives up the speed of forms that have proved themselves.

      3. The desk adds a new form type, handwritten notes, and there are 0 labelled examples. Claude rates them at 0.96. How should the router treat them?

      1. AApprove them, since the typed forms and the scans both passed review.
      2. BApprove them, since 0.96 is above the bar the router already uses.
      3. CApprove them while the overall accuracy stays above the target.
      4. DHold them until the type has been measured against labels.
      Show the answer

      Answer: D

      • A Trust belongs to a measured type. A new type has not earned what another type earned.
      • B The number is a self-rating, and for this type nobody has checked it.
      • C The overall figure is dominated by the larger types and cannot vouch for a new one.
      • D Correct. An unmeasured segment is held, however confident Claude sounds.

      4. Which two measurements should be in place before a form type skips review? Select two.

      1. AThe overall accuracy across every form type, as one figure.
      2. BAccuracy for that form type, against human labels.
      3. CAccuracy for each field, such as the amount, within that type.
      4. DThe average confidence Claude reports for that type.
      Show the answer

      Answer: B, C

      • A One blended figure can be high while a single type or field is poor.
      • B Correct. A type is trusted on its own measured accuracy.
      • C Correct. A type can be right on the name and wrong on the amount, so fields are measured too.
      • D This is Claude's opinion of its own work, not a measurement.

      5. A scanned form reads 128.00 when the paper says 126.00. The value is a well-formed amount and Claude wrote 0.95. Which check catches it?

      1. AA check that the amount is a number.
      2. BA comparison with the labelled amount, reported for the scanned type.
      3. CA second question asking Claude whether it is sure.
      4. DHolding every form that has a decimal point in it.
      Show the answer

      Answer: B

      • A A well-formed number can still be wrong, so this check passes it.
      • B Correct. Only the label knows the paper said 126.00, and the type's accuracy follows from it.
      • C Claude rates the same text it just read, so it tends to repeat the same answer.
      • D Most decimal amounts are right. This holds good rows and does not target the weak type.

      6. A scanned form has no amount at all, and Claude returns a confidence of 0.97 with the amount empty. What should the router do?

      1. AApprove it, because the confidence clears the bar.
      2. BAsk Claude to lower its own confidence and route again.
      3. CHold every form in the queue until this one is resolved.
      4. DHold this row for a human, since there is no value to approve.
      Show the answer

      Answer: D

      • A A high number beside an empty field is a mismatch, and approving it sends nothing to the ledger.
      • B Claude adjusting its own number does not add the missing amount.
      • C One empty row does not make the other rows wrong.
      • D Correct. A row with no value goes to a human even when the number beside it is high.

      7. Approved rows are never looked at again, and a type that was 98% right last month has drifted. How does the team find out?

      1. ASample a few approved rows from each type at random and compare them with labels.
      2. BSample only the rows with the lowest confidence, since those are likeliest to be wrong.
      3. CRecompute the overall accuracy from the rows that were reviewed.
      4. DStop approving anything automatically until the month ends.
      Show the answer

      Answer: A

      • A Correct. A random sample of the approved rows keeps measuring the error the router cannot see.
      • B Approved rows are the high scores. Drift hides in rows that looked fine.
      • C Reviewed rows were the ones already held, so they say nothing about approved rows.
      • D This stops the drift by stopping the automation, and it is not a measurement.

      8. Which two things must a review sample of approved rows include? Select two.

      1. ARows from every form type that is approved.
      2. BOnly the rows Claude rated the lowest.
      3. CEvery approved row, so nothing is missed.
      4. DRows chosen at random inside each type.
      Show the answer

      Answer: A, D

      • A Correct. A type left out of the sample is a type nobody is measuring.
      • B Low scores were probably not approved, so this sample misses the rows that need checking.
      • C Checking every row removes the saving the router was built to give.
      • D Correct. Random picks stop the sample from repeating the rows that were easy to choose.

      9. Two forms give different totals for the same order, 84.00 and 48.00. Both are read at high confidence. What should the record keep?

      1. AThe value with the higher confidence, and drop the other.
      2. BNeither value, and ask a human to retype the order from scratch.
      3. CBoth values, each with the form it came from.
      4. DThe value Claude says it trusts more, after asking it.
      Show the answer

      Answer: C

      • A Two confidence numbers that are both high do not settle which form is right.
      • B Throwing away both loses what a human needs to resolve it.
      • C Correct. Keeping both with their sources lets a human decide with the evidence in front of them.
      • D Claude has no fresh information, so asking again repeats its guess.

      10. A field in a faded scan cannot be told apart from a similar digit, and the source is unclear. What happens to that field?

      1. AIt is approved at the confidence Claude gave it.
      2. BIt goes to a human, with the scan attached.
      3. CClaude is asked to guess again until two readings match.
      4. DThe whole queue waits until every unclear field is settled.
      Show the answer

      Answer: B

      • A A confident guess about an unclear source is still a guess.
      • B Correct. A human can look at the paper, which the model cannot do better than it did.
      • C Two matching guesses from the same unclear text are not evidence.
      • D The other rows are clear, so holding them costs time and buys nothing.

      11. A report says a refund total was 96.50 and does not say which form it came from or when it was read. What is missing?

      1. AThe source and the date, kept next to the value.
      2. BAn average accuracy figure for the month.
      3. CA higher confidence score beside the total.
      4. DA sentence from Claude saying the total is reliable.
      Show the answer

      Answer: A

      • A Correct. A value with no source or date cannot be checked or told apart from an older one.
      • B An average about the month says nothing about where this one total came from.
      • C Confidence is about the reading, and it does not say where the value came from.
      • D A claim of reliability is not provenance.

      12. Which two items should survive with each extracted value when the record is passed on? Select two.

      1. AThe confidence number, used as proof that it is right.
      2. BThe source the value was read from.
      3. CThe overall accuracy of the whole pipeline.
      4. DThe date the value was read.
      Show the answer

      Answer: B, D

      • A The number is a self-rating and proves nothing on its own.
      • B Correct. The source lets the next reader check the value against the paper.
      • C The pipeline figure describes all rows, and it does not describe this one.
      • D Correct. The date shows whether a newer reading would replace it.

      Conclusions

      • A confidence Claude reports is a self-rating. It routes nothing until it is checked against labels.
      • An overall accuracy hides a weak segment. Report accuracy by form type and by field.
      • A segment skips a human only after it meets its target. An unmeasured segment is held.

      You can now route work on measured accuracy instead of a number Claude gives.
