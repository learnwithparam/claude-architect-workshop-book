      Rules decide who takes over, and the handoff carries the case

      Three rules as written

      route in the starting code escalates on tone: two exclamation marks or the word "ridiculous". Tone is not difficulty. An angry customer with a simple refund is easy, and a calm customer who wants a policy the shop lacks is hard.

      Sentiment does not measure difficulty, and neither does the model rating its own confidence. A rule needs a signal that names the ticket, such as a request for a person.

      A prompt line that says not to invent policies only lowers the rate. When the shop has no policy, route to a person in code before the agent answers.

      Three rules replace tone with criteria

      Escalate on an explicit request for a person, or on a policy the shop does not have. Ask when two customers match. The text matches in route stand in for a real classifier.

      When the model must judge the gray cases, write two to four worked examples, each a sample ticket with the right call and its reason. A reason teaches the boundary, which a bare label cannot. "Be conservative" is not a criterion, because it names no case.

      Split a message that holds several asks into items, and decide each one. The routing is plain code, so the same ticket goes the same way every time.

      The shop has no price match policy, so a person must decide. With the starting rules the handoff is one line. Press the second button: the handoff holds five fields, which are customer, order, issue, what was tried, and the ask.

      A handoff is a data structure, not a sentence. The person who opens it should not have to ask the customer again.

      The same care applies to alert flags that tell staff a ticket needs a look. If one flag category fires on 40 percent of tickets, staff stop reading every flag. Switch that category off until its criteria are fixed, and keep the others on.

      Check your understanding

      Answer each question, then read why every option is right or wrong. The wrong options are the mistakes engineers make on the job.

      1. A team escalates every ticket with an angry tone. Of 100 escalations last week, 34 were simple refunds the agent could have finished. What is the right change?

      1. AEscalate on named criteria, such as a request for a person or a policy the shop lacks.
      2. BHire more people for the escalation queue, so the extra 34 are handled quickly.
      3. CAdd more angry words to the rule, so the tone check is more exact.
      4. DKeep the tone rule and add a sentiment score, escalating only when the score is very low.
      Show the answer

      Answer: A

      • A Correct. A criterion says something about the ticket, such as what is asked or whether a policy exists.
      • B More staff clears the queue and leaves the rule unchanged. The 34 simple refunds still reach a person.
      • C A longer word list misses calm hard tickets and still catches angry easy ones.
      • D A sentiment score is still tone. A calm ticket can be hard, and an angry one can be a simple refund.

      2. Select two valid triggers for sending a ticket to a person.

      1. AThe customer asks for a person.
      2. BThe sentiment score of the message is below a threshold.
      3. CThe shop has no policy for what the customer asks.
      4. DThe model rates its own confidence under 0.8.
      Show the answer

      Answer: A, C

      • A Correct. An explicit request is honoured at once.
      • B Sentiment measures tone, not difficulty. A calm ticket can need a person and an angry one may not.
      • C Correct. When the policy is silent the agent would have to invent one, so a person decides.
      • D A model's rating of itself does not track whether it is right, so it cannot route tickets.

      3. A lookup for Sam Lee returns two customers, and the agent answers about the first one. In 50 such tickets, 19 were about the wrong person. What should the lookup do?

      1. AReturn the first match, because the first record is right more often than not.
      2. BReturn the account with the newest order, since it is more likely to be active.
      3. CReturn a question asking for one more identifier, such as the email.
      4. DSend every name collision to a person, so nobody has to choose.
      Show the answer

      Answer: C

      • A The first record is an arbitrary pick. In the tickets above it was wrong 19 times in 50.
      • B Recency is a guess. The customer who wrote in may be the one with the older account.
      • C Correct. One more identifier settles it, and the agent never has to guess.
      • D A collision can be settled by one question. Sending it to a person spends a person on a simple case.

      4. A routing rule sends a ticket to a person when the model rates its own confidence under 0.7. The model rated 0.9 on an answer that was wrong. What does this show?

      1. AThe threshold is too low, so raising it to 0.95 will catch this kind of miss.
      2. BThe model should rate its confidence a second time, and the second rating is the one to use.
      3. CAveraging three ratings will give a number that follows whether the answer is right.
      4. DSelf-rated confidence does not measure difficulty, so route on explicit criteria.
      Show the answer

      Answer: D

      • A A higher threshold still relies on a number that can be 0.9 on a wrong answer.
      • B A second rating comes from the same source and has the same flaw.
      • C An average of numbers that do not track correctness does not track it either.
      • D Correct. Name the triggers, and check accuracy against labelled tickets instead of trusting a score.

      5. A customer writes "I want a person" after three replies from the agent. The agent writes a fourth answer. What should happen instead?

      1. AThe agent tries one more answer first, since it might solve the ticket.
      2. BThe ticket goes to a person at once.
      3. CThe agent asks the customer to confirm that they really want a person.
      4. DThe agent waits to see whether the next message sounds angry.
      Show the answer

      Answer: B

      • A The customer has already asked. A fourth attempt repeats what they are tired of.
      • B Correct. An explicit request is a rule with no judgement in it, so it is honoured at once.
      • C A confirmation turns a clear request into one more step the customer did not ask for.
      • D Tone is not the trigger. The customer has already said what they want.

      6. A customer asks for a price match, which the shop has never offered. The agent quotes a price match policy it made up, in 12 of 40 such tickets. What is the right fix?

      1. AAdd a line to the prompt that says not to invent policies.
      2. BLet the agent offer the nearest policy it has, such as a return window.
      3. CLower the temperature so the agent stays closer to the facts it has.
      4. DEscalate to a person in code whenever the policy is silent.
      Show the answer

      Answer: D

      • A A prompt line lowers the rate but is still a request, and 12 in 40 shows how often it slips.
      • B A different policy is still not the one asked for, and the customer is misled.
      • C Temperature changes variety, not whether the agent knows a policy exists.
      • D Correct. A named criterion sends the ticket to a person, and no policy gets invented.

      7. The prompt says "be conservative about escalating". On 60 borderline tickets, 18 go the wrong way. What should change?

      1. AMake it stronger, for example "be very conservative about escalating".
      2. BHave the model rate its confidence and escalate below a threshold.
      3. CName the categories, what to escalate in each and what to handle.
      4. DEscalate every borderline ticket, so none are handled wrongly.
      Show the answer

      Answer: C

      • A A stronger word is still not a criterion. The model still has to guess what conservative means.
      • B A confidence rating does not track whether the ticket is hard.
      • C Correct. Named categories with a clear action each leave the model nothing to guess.
      • D This fixes the 18 by sending all 60 to people, which is the cost the agent was built to avoid.

      8. One flag category is raised on 40 percent of tickets, and staff have stopped reading any flags. What is the best response?

      1. ASwitch that category off until its criteria are fixed.
      2. BAsk staff to read every flag, since the noisy category may hide real ones.
      3. CReword the flag so it sounds less urgent, so staff take it less seriously.
      4. DRemove all flagging, so nobody has to sift through them.
      Show the answer

      Answer: A

      • A Correct. Trust is restored by removing the noise, and the category comes back once its criteria are sound.
      • B Staff already stopped. A flag nobody trusts costs time and protects no one.
      • C A quieter flag on 40 percent of tickets is still noise.
      • D This drops the useful flags along with the noisy one.

      9. An escalation note reads "customer unhappy". The person who takes the ticket has to ask the customer everything again, and handling time is 11 minutes longer. What is the fix?

      • B A transcript holds the answer but buries it, so the person still starts from zero.
      • C Correct. Each field answers a question the person would otherwise put to the customer.
      • D A mood score says how the customer feels and not what to do.

      11. One message asks for a refund and an address change. The agent answers the refund and ignores the address in 14 of 30 such messages. What should change?

      • D More variety makes the runs differ more, not less.
