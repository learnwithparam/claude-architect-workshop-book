      Worse after Friday, and a prompt that grew

      Lumen Supply is an online electronics shop. Its agent answers a policy question from the passage that the help centre returns for it.

      The Friday release touched the layers that can break an answer: the index, the lookup tool, the model setting and the prompt. On Monday the answers are worse. A developer adds "do not make things up" to the prompt, and it grows by twelve lines of rules. The wrong answers continue.

      Three things go wrong, in this order. A prompt rule is added for a fault that sits in retrieval. No baseline run exists, so nobody can say which cases flipped. And the fix is not kept as a regression case, so the fault can come back.

      The ladder, written as code

      A release can change several layers at once, so ladder takes the list of layers that changed. It returns the one to check first: the index, then the tool, then the model, and the prompt last.

      The order follows the path of the data. A wrong passage ruins every layer after it, so the index comes first. The prompt is the easiest layer to edit, and that is why teams reach for it first.

      Change one layer per run. Then a flip has one cause, and the ladder's answer can be tested.

      Keep it as a regression case

      The run lists the flips, names the layer, and then keeps every flipped case with its question and expected value. After the fix it checks that each kept case is right again.

      A guardrail is a check with an address puts a check at each layer, so a fault like this one fails a test on the day it appears. Until then, the flip list and the regression slice are the record of what changed.

      Check your understanding

      Answer each question, then read why every option is right or wrong. The wrong options are the mistakes engineers make on the job.

      1. Answers from the support agent got worse after a Friday release. Accuracy fell from 40 of 40 to 30 of 40 cases, and the release also rebuilt the retrieval index on Thursday and added four lines to the prompt. The team has one afternoon and a saved baseline run. What should they do first?

      1. ARewrite the four new prompt lines, since the prompt is the layer the team can edit fastest and test today.
      2. BAdd a rule telling the agent never to answer when it is unsure, and run the 40 cases again.
      3. CRe-run the 40 cases with the old index, then compare the passages in the failing cases.
      4. DSwitch to a larger model for the afternoon and see whether accuracy returns to 40 of 40.
      Show the answer

      Answer: C

      • A The prompt is the last layer on the ladder. Editing it first can hide an index fault for a day and leave the cause in place.
      • B A rule about unsure answers does not reach a fault where the agent was given the wrong page. It answers correctly for that page.
      • C Correct. The index is the first layer that changed, so the team checks it against the baseline and reads the passages that the failing cases were shown.
      • D A larger model reads the same wrong page and gives the same wrong value. The model is rarely the cause of a fault that follows a release.

      2. A developer added "do not make things up" and eleven other lines to the support prompt after answers got worse. The next run still gets 30 of 40 cases right, and the same 10 cases are wrong. Every wrong answer matches the passage the agent was given. What does this result show about the fault?

      1. AThe fault is upstream of the prompt, so check what was retrieved for those 10 cases.
      2. BThe prompt needs more rules, because 10 cases is a small number and the rules so far were too general to help.
      3. CThe agent ignores the prompt, so the next step is a model that follows instructions better.
      4. DThe 40 cases are at fault, so the 10 cases should be removed from the set and the run repeated.
      Show the answer

      Answer: A

      • A Correct. The answers follow the passages, so the prompt did its job. The fault is upstream, and the passages for those 10 cases show whether retrieval found the right page.
      • B More rules add lines and leave the wrong passage where it was. The same 10 cases stay wrong because the prompt never changed what the agent was shown.
      • C The agent followed the prompt and answered from the passage. Every answer matches its passage, so it did not ignore anything.
      • D Removing failing cases raises the score and keeps the fault. The 10 cases are the evidence that points at the layer.

      3. One Friday release changed the lookup tool, the prompt and the model setting together. Answers are worse, with 28 of 40 cases right against 40 of 40 on the last good run. The team wants to know which change caused it and has the same 40 cases and the old version of each layer. How should they find out?

      1. ARead the diff of all three changes, pick the one that looks riskiest and revert it.
      2. BRevert all three changes, ship the old version and leave the question of the cause open.
      3. CAdd a rule to the prompt for each symptom in the failing cases and run the 40 again.
      4. DApply the changes one at a time to the old version and run the 40 cases after each.
      Show the answer

      Answer: D

      • A A guess from a diff is not a measurement. The riskiest-looking change is often not the one that flipped the cases.
      • B Reverting everything restores the old answers and teaches nothing. The same mix of changes will be shipped again later.
      • C Rules for symptoms grow the prompt and leave the cause alone. The team would not know which change was at fault.
      • D Correct. One change per run gives each flip one cause, and each run is compared with the baseline on the same 40 cases.

      4. In a postmortem after a Friday incident, the index change flipped 10 of 40 cases and a fix restored all 40 after two days. The team wants the postmortem to stop the same fault from returning unseen. Which two things should the team keep from the diagnosis? Select two.

      1. AThe list of flipped cases, with each question and its expected value.
      2. BA list of the prompt rules that were tried and did not help, with the date of each try.
      3. CA regression case for each flipped case, run with every later release.
      4. DThe name of the developer who built the new index, so the team knows who to ask.
      Show the answer

      Answer: A, C

      • A Correct. The flipped cases are the exact evidence of what broke, and each has a question and a value that can be checked again.
      • B Rules that did not help are a record of what was tried, and they keep no fault from returning. They also add lines to the prompt.
      • C Correct. A fixed fault kept as a test fails on the day it returns, so the fix does not depend on anyone remembering it.
      • D A name may help a follow-up conversation, and it checks nothing in the next release.

      5. A bad run of 40 cases shows 12 wrong answers that all say the value is not stated. The team has the run, the passage shown for each case and the raw result of the lookup tool, and only an hour before the next release. Which two things should the team read first in this bad run? Select two.

      1. AThe prompt text, line by line, for a rule that might suppress answers.
      2. BThe passage the agent was shown for each of the 12 cases.
      3. CThe accuracy of the same agent on another dataset of questions.
      4. DThe raw result of the lookup tool for one failing case.
      Show the answer

      Answer: B, D

      • A The prompt is the last layer to check. A rule that suppresses answers is possible, and it is the most likely reading of the symptom only after the earlier layers are cleared.
      • B Correct. The passage is the input the agent answered from. A passage without the value explains an answer that says the value is not stated.
      • C Another dataset shows how the agent does elsewhere and says nothing about these 12 cases. The evidence is in this run.
      • D Correct. The tool result shows whether the tool handed over the full passage or a cut one, which is a tool fault and not a prompt fault.

      6. A trace of a failing case shows the lookup tool returned an empty result for a refund limit question. The agent then answered with a plausible dollar figure that is wrong, and 4 of the 40 cases fail in the same way. The prompt has not changed since the last good run. Where is the fault?

      1. AThe prompt, because it should forbid a guess when the tool returns nothing.
      2. BThe tool, because it handed over nothing and the agent had nothing to read.
      3. CThe model, because it should refuse instead of inventing a number.
      4. DThe dataset, because 4 of 40 is too few failures to draw a conclusion.
      Show the answer

      Answer: B

      • A A rule may make the symptom rarer and leaves the empty result where it is. The tool still fails on the next question.
      • B Correct. The first wrong thing in the trace is the empty result. The agent answered without a passage, and fixing the tool removes the cause.
      • C A guess after an empty result is the symptom. The earlier layer, the tool, is the first place to check.
      • D Four failures that share a cause on the same kind of question are a pattern. Comparing with the baseline shows them as flips.

      7. After the index was rebuilt, 10 of 40 answers cite a policy page that was retired in March, and each of them gives the old value. The prompt and the model setting did not change. The retired pages were added to the new index by mistake. What should the team check first?

      1. AWhether the prompt tells the agent to prefer the newest page when two pages differ.
      2. BWhether a larger model reads the two pages and picks the right value by itself.
      3. CWhether the new index still filters out retired pages when it ranks the passages.
      4. DWhether the 10 questions are phrased more loosely than the other 30.
      Show the answer

      Answer: C

      • A The agent is shown one passage, so it has no second page to prefer. The wrong page is chosen before the prompt is read.
      • B The agent never sees both pages, so a stronger model cannot choose between them. The fault happens at retrieval.
      • C Correct. The rebuilt index is the layer that changed. Without a version filter the retired page competes with the current page and can win.
      • D Wording decides which page wins only because the index has no filter. Checking the filter addresses the cause.

      8. A chunking change on the index lowers recall at 3 from 95% to 80% on the 40 questions. The right passage is now missing from the top 3 results for 6 more questions. The prompt is unchanged, and answers for those 6 questions are wrong. What should the team do?

      1. AAdd a prompt rule that says to answer only when the value is in the passage, and run the 40 again.
      2. BRaise the number of passages in the prompt until the answers look right again on the 6 questions.
      3. CMove the six questions to a separate dataset and report recall on the rest of the set.
      4. DFix or revert the chunking, then measure recall at 3 on the same 40 questions.
      Show the answer

      Answer: D

      • A The rule would make the agent refuse when the value is missing, and the value is missing because retrieval lost it. The wrong answers become no answers.
      • B More passages can hide the loss on a few questions and raise cost and noise everywhere. Without a measurement the team cannot tell whether the loss was fixed.
      • C Moving the six questions away removes the evidence and keeps the fault. The recall figure would rise without any fix.
      • D Correct. The chunking is the change, so the team fixes it and measures recall again on the same 40 questions to show the loss is gone.

      9. A team ships a new index and reads the score a week later. The average looks steady at 38 of 40, and nobody listed which cases changed. Support then reports 5 wrong refund answers that were right before the release. What should the team have done before shipping?

      1. AWaited a week more, so the average would settle into a clearer number.
      2. BList the flipped cases against the baseline run, and keep each fixed one as a case.
      3. CRead the average again with a second reviewer, so a drop would be seen by two people.
      4. DAdded a prompt rule for refund answers, since refunds are where the errors appeared.
      Show the answer

      Answer: B

      • A Waiting gives more time for wrong answers and no better view of which cases changed. The average hides cases that flip in both directions.
      • B Correct. A list of flips against the baseline run names the 5 wrong refund answers before shipping, and each becomes a regression case.
      • C A second reviewer of the same average sees the same average. The 5 cases are visible only when the two runs are compared case by case.
      • D A rule aimed at refunds treats one symptom and leaves the index that caused it. The list of flips would have pointed at the cause.

      10. A change to the lookup tool raises the average from 34 to 36 of 40 cases. The team wants to keep it. The comparison with the baseline shows that 4 cases that were right before are now wrong, and 6 cases that were wrong are now right. How should the team decide?

      1. AName the 4 flipped cases and decide against the limit written before the run.
      2. BKeep the change, because 6 cases improved and 4 got worse, and the net result is better.
      3. CReject the change, because any case that gets worse is a reason to revert.
      4. DRun the 40 cases three more times and keep the change if the average stays above 34.
      Show the answer

      Answer: A

      • A Correct. The 4 flipped cases are a list a person can read, and the limit written before the run says whether they are acceptable.
      • B A net gain can hide 4 cases that matter more than the 6 that improved. The decision needs the names of the flipped cases.
      • C A rule that allows no flip would block most useful changes. The limit must be written first, so the decision is not made by reflex.
      • D More runs of the same average show that it is stable and say nothing about the 4 flipped cases.
