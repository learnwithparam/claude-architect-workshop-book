export async function tax(id: string): Promise<number> {
  const order = await fetchOrder(id);
  return order.total;
}

- I didn't touch the import lines or the file layout. Each module is still one file.

      Say when to plan and when to edit

      The fix is two bullets, and the house facts stay. A change to more than three files, or one with several valid approaches, gets a list of every file and a stop for approval. A fix in one file with one clear answer is edited directly.

      Claude Code also has a plan mode, switched on with --permission-mode plan. It blocks every edit for the session. The team file sets the habit for everyone, and still lets a one-file fix through.

      Planning is one way to choose a shape for the work. A fixed chain runs the same steps in order, such as 4 checks on each pull request, then a last pass on how the parts fit. An adaptive plan lets each finding pick the next step, which suits an open investigation.

      Check your understanding

      Answer each question, then read why every option is right or wrong. The wrong options are the mistakes engineers make on the job.

      1. A migration touches many modules, and the edits collide in one module because nobody agreed the approach. What is the best fix?

      1. AEdit the modules one at a time and re-run the tests after each edit.
      2. BUse plan mode first, agree the approach, then execute the edits.
      3. CPlan every change from now on, including one-line fixes.
      4. DRun the same migration again with a longer prompt.
      Show the answer

      Answer: B

      • A Testing after each edit finds collisions late. The approach is still undecided.
      • B Correct. A plan agrees the design before any module changes.
      • C Planning a one-line fix costs more than the fix. Match the effort to the change.
      • D A longer prompt still starts editing at once, with no agreed approach.

      2. A stack trace points at one line in one file, and the fix is clear. A plan would take 40 minutes. What is the best way to work?

      1. APlan it in plan mode so a person approves the edit first.
      2. BSplit the fix across two sessions so each one stays short and cheap.
      3. CInterview Claude about the design before touching the file.
      4. DEdit it directly. One file with one answer needs no plan.
      Show the answer

      Answer: D

      • A A plan adds 40 minutes to an answer that is already clear.
      • B Two sessions add overhead to a one-line change.
      • C An interview is for open decisions. This one has none.
      • D Correct. A small, clear fix is edited directly.

      • C Tests check behavior. They do not compare three designs.
