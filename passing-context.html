      Foundations, lesson 11

      Passing context

      A subagent knows only what its prompt holds

      A coordinator collects findings from researchers, then starts a writer subagent to draft the recall report. The writer is handed the task and nothing else. It cannot name a source for any claim, and nobody can check a figure. This is the agent at Lumen Supply, an online electronics shop. You will watch the writer work with no findings, then fix the handoff so every claim keeps its source and date.

      I doWatch the failure and its fix.

      The brief is the writer's whole world

      A subagent starts fresh, with its own prompt and tools. It does not see the coordinator's turns, the researchers' notes or the tool results the coordinator read. Whatever the writer must use has to be in the prompt the coordinator writes. That prompt is the brief.

      This design fails in three ways. The findings never reach the writer, a summary drops each source, and two figures that differ only by date look like a conflict. You will see the first fail, then fix it, then see the third.

      Do not solve this by sending the whole history. Every request carries it, so each call costs more as it grows, and early facts get buried in the middle of a long input. Send the findings the writer needs and nothing more.

      A brief with findings gives a sourced report

      The brief holds the task and every finding. Each one has its claim, its evidence, its source and its date. The coordinator starts the writer with the Agent tool, called Task in older releases, and gives the brief as the prompt.

      The brief as written

      brief turns the task and the findings into the writer's prompt. The starting version passes the task and ignores the findings, so the writer has nothing to cite.

      Findings cost little to pass. Each one is about 40 tokens, so twelve are about 480 tokens. Passing none costs 0 and loses every citation.

      Two habits keep the brief lean. Ask each researcher to return only the few fields the writer needs, with the source and date kept on each claim. Tell a subagent what is already covered, so it does not repeat a search the coordinator finished.

      Pass the claim, evidence, source and date

      The fix writes each finding into the brief as one block with separate fields: the claim, the evidence, the source and the date. It then asks for one line per finding, each ending with its source and date.

      Keeping the four fields apart is what lets a source survive the writing. Data and its metadata travel together.

      Check your understanding

      Answer each question, then read why every option is right or wrong. The wrong options are the mistakes engineers make on the job.

      1. A writer subagent returns a fluent recall report with no sources. The coordinator read six sourced findings earlier in its session and then asked the writer to write the report. What is the root fix?

      1. AAsk the writer to be more careful about sources, since it has the same session as the coordinator.
      2. BPaste the six findings, each with its source and date, into the writer's prompt.
      3. CRaise the writer's turn limit from 4 to 12 so it can search for the sources itself.
      4. DAsk a second writer to edit the report and add the missing citations afterwards.
      Show the answer

      Answer: B

      • A The writer does not share the session. Care cannot cite what it has never seen.
      • B Correct. A subagent knows only its prompt, so whatever the writer must cite has to be in it.
      • C More turns let it guess longer. The sources are in the coordinator, and a limit does not move them.
      • D A second writer starts just as fresh, with no findings. It can only invent a citation.

      2. A subagent repeats a search the coordinator finished an hour ago, and 9 of its 12 queries match earlier ones. The coordinator's history holds the results. What fixes the repeat?

      1. AGive the subagent read access to the coordinator's conversation so it can look for itself.
      2. BTell the coordinator to run every search twice so one copy is always in the subagent's cache.
      3. CAsk the subagent to write shorter queries, since long queries are likely to match older ones.
      4. DPass the earlier findings in the subagent's prompt and tell it what is already covered.
      Show the answer

      Answer: D

      • A A subagent starts with a fresh context and does not see the coordinator's turns.
      • B A cache is not a context. The duplicate work doubles and the subagent still does not know the results.
      • C Query length is not the cause. The subagent does not know what was already searched.
      • D Correct. The subagent has no history, so the prompt is the only place the earlier work can reach it.

      3. A coordinator pastes 12 findings into the writer's prompt as one paragraph of prose. The report cites 4 sources and gets the dates wrong for 7 claims. What change keeps the metadata?

      1. AKeep each claim, its evidence, its source and its date as separate fields in the brief.
      2. BAsk the coordinator to write a shorter paragraph so the writer can hold all 12 facts at once.
      3. CTell the writer to add the dates from memory when a claim has none, to keep every line uniform.
      4. DMove the source names to the start of the paragraph, before the first claim.
      Show the answer

      Answer: A

      • A Correct. Separate fields let the source and date travel with the claim, so nothing has to be guessed from prose.
      • B Shorter prose drops more detail. The loss comes from blending fields, not from length.
      • C Memory is how an invented date gets into a report. The date has to be in the brief.
      • D Moving the names does not tie each one to its claim. The link is lost either way.

      4. Select two statements that are true of a subagent started by a coordinator.

      1. AIt starts fresh, with none of the coordinator's turns.
      2. BIt sees the findings the coordinator read, because both work on one request.
      3. CIt learns about the task only from the prompt it was given.
      4. DIt reads the coordinator's earlier tool results when it needs a source to cite.
      Show the answer

      Answer: A, C

      • A Correct. The coordinator's turns and tool results are not copied into it.
      • B They work on one request but hold separate contexts.
      • C Correct. Anything the coordinator read and did not write into the brief is missing for the subagent.
      • D Tool results stay in the coordinator's context. The subagent only sees what the brief repeats.

      5. A coordinator merges 12 findings into one summary paragraph for the writer. The report reads well but a reviewer cannot trace 9 of its claims to a source. What should the coordinator keep?

      1. AA longer summary, so the 9 untraceable claims each get a full sentence of their own.
      2. BOnly the claims that more than one researcher found, since those need no source.
      3. CThe mapping from each claim to its source, passed along with the claim.
      4. DA note at the top of the report saying the claims come from trusted researchers.
      Show the answer

      Answer: C

      • A A longer summary still has no source attached. The mapping is what is missing.
      • B Agreement between researchers is not a citation. A reviewer still has nothing to check.
      • C Correct. A claim with its source can be checked. A summary without the mapping cannot.
      • D A general note names no source. Each claim needs its own.

      6. A lab report says 12 percent of units failed, while a retailer call says 15 percent. A reviewer asks the writer which figure is right. What should the report do?

      1. AShow both figures, each with its source, and say which numbers conflict.
      2. BReport the 15 percent, since the higher figure is the safer one for a recall.
      3. CAverage the two and report 13.5 percent with no sources, to keep the line short.
      4. DDrop both figures and write that failures were reported, to avoid taking a side.
      Show the answer

      Answer: A

      • A Correct. The reader can judge the gap only when both figures and their sources are visible.
      • B Choosing by size hides the other source. The reader cannot see the conflict.
      • C An average belongs to neither source and cannot be checked.
      • D Dropping both loses the evidence. The report should show the conflict.

      7. A report holds two figures for swollen units: 40 from a 9 March field report and 65 from an 18 March field update. A reviewer calls it a contradiction. What explains it?

      1. AOne of the two sources is wrong, so the writer should keep the newer one and drop the other.
      2. BThe dates differ, so the later figure may count units that swelled after the first report.
      3. CThe writer rounded one of them, so the figures should be averaged to 52.5.
      4. DThe researchers used different search tools, so the figures cannot be compared at all.
      Show the answer

      Answer: B

      • A Nothing says either is wrong. Dropping one throws away the trend.
      • B Correct. A date often explains a gap. Keeping both dates lets the reader see that.
      • C An average hides both the dates and the two sources.
      • D Different tools do not make two dated counts incomparable. The dates are the difference.

      8. A report holds quarterly financial figures from 4 sources. Select two rules for presenting them.

      1. AWrite them as flowing prose, since one format suits every kind of content.
      2. BUse a table, since numbers are easier to compare across rows and columns.
      3. CPut the sources in a single list at the bottom, since rows read more cleanly without them.
      4. DKeep the source with each row, so every figure can be traced.
      Show the answer

      Answer: B, D

      • A A table suits figures, prose suits narrative. One format does not suit both.
      • B Correct. Finance figures are compared by row and column, which is what a table is for.
      • C A list at the end breaks the link between a figure and its source.
      • D Correct. Without a source beside the row, the reader cannot check a number.

      9. A coordinator passes a 60,000 token input to the writer. The 2 findings that matter most sit in the middle and the report misses both. What helps most?

      1. ALeave them in the middle and ask the writer to read the whole input twice.
      2. BMove to a model with a larger window, so 60,000 tokens no longer counts as long.
      3. CAdd a sentence at the end saying the middle of the input is important.
      4. DPut the key findings at the start under clear headings and trim the rest.
      Show the answer

      Answer: D

      • A Asking twice does not change where the model attends. The position is the problem.
      • B A larger window holds more, but key facts in the middle are still missed.
      • C A sentence at the end does not bring the middle findings forward.
      • D Correct. Models read the edges of a long input most reliably, so headings and position help.

      10. A researcher returns 40 fields per finding and the writer uses 5 of them. The report still loses dates. What should the researcher return?

      1. AAll 40 fields, since the writer can decide which to use for its report.
      2. BOnly the claims, since the source and date are kept in the coordinator's notes.
      3. CThe few fields the writer needs, including the source and the date with each finding.
      4. DA one-line summary per finding, to cut the result from 40 fields to 1.
      Show the answer

      Answer: C

      • A Extra fields bury the few that matter and fill the context.
      • B The writer does not see the coordinator's notes. The metadata must travel with the claim.
      • C Correct. A smaller result keeps the context lean, and the date and source still travel with the claim.
      • D A summary drops the source and date that the report needs.

      11. A report passes through 3 rounds of summary. A finding of 12.5 percent comes out as about 12 percent, and the source is gone. What prevents it?

      1. AAsk each round to summarize more carefully, since the wording is the source of the loss.
      2. BAdd a fourth round that compares the summary with the first to catch any drift.
      3. CRaise the context window so all 3 rounds fit without any trimming.
      4. DKeep the facts in a block outside the summary and pass them unchanged.
      Show the answer

      Answer: D

      • A Careful wording still rounds and drops. The fix is to stop re-summarizing the facts.
      • B The first summary has already lost the detail. A comparison cannot restore it.
      • C Fit is not the issue. Each round still blurs the figure.
      • D Correct. Each summary rounds and drops detail, so the exact figures and sources stay in a block of their own.

      12. A coordinator keeps a long history of 80 turns and sends every turn to each new subagent. Select two effects of a long history.

      1. AEvery request carries it, so each call costs more as the history grows.
      2. BOlder turns are read better than new ones, since the model reads from the start.
      3. CA bigger window removes the cost, since nothing has to be trimmed any more.
      4. DOld detail is buried, so early facts are easier to miss in the middle.
      Show the answer

      Answer: A, D

      • A Correct. The whole history is sent with each request, so cost and delay grow with it.
      • B Attention to the middle falls off. Age alone does not make a turn clearer.
      • C A bigger window holds more, but the cost of carrying it stays.
      • D Correct. Facts placed early in a long input compete with everything after them.
