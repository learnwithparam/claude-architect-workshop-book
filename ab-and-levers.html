      A 22% saving and a 2 point loss

      Lumen Supply is an online electronics shop. Its agent reads a ticket and picks one action: refund, deny, escalate or ask for the order number.

      Two changes are proposed: a cheaper tier and a shorter prompt. Each runs on the same 100 recorded tickets next to the current setup, and the customer sees none of it.

      Three things go wrong, in this order. The ship rule is written after the result, so it can always be met. A lever has no guard metric, so a gain in one place hides a loss in another. And the change goes straight to all traffic with no shadow run.

      The ship rule, written as code

      rule writes down the metric, the threshold and one guard metric before anyone sees a number. The threshold is the smallest saving that counts. Guard metrics are second metrics the lever must not hurt, here accuracy. decide reads both from the saved rule and returns a verdict with its reason.

      Cost is tokens times price. The current setup uses about 123 input tokens and 9 output tokens a ticket on Haiku 5.5, at $0.10 and $0.50 per million tokens. Times 10,000 tickets that is about $0.17.

      Three levers cut that cost: a cheaper tier, a shorter prompt, and a cached prefix. A cached prefix bills the long policy text at a lower rate when the same text opens every request. This lab runs the first two, and each lever gets its own guard metric.

      The larger tier's prices are this lab's figures, so check the pricing page before you use them. Output tokens are estimated from the reply size.

      Pre-register, guard, then decide

      rule is written and saved before the run. decide reads the saved threshold and guard, and returns not-ship with the reason when its guard metric is breached. The same run now reads "guard breached: accuracy fell 2.0 points, the limit is 1.0".

      Every lever needs its own guard metric. A cheaper tier needs an accuracy limit. A change that lifts accuracy needs a latency limit and a cost limit, because it can double the wait.

      Fix the sample size and the rule before the run, and read the result once. A team that checks the gap each morning and ships on the first good day is peeking. Every extra look is another chance to catch a lead that is only noise.

      Run it in shadow first

      In production, a shadow run answers live tickets with both variants and sends the customer only the current one. Guard metrics are then measured on real load. This lab uses a recorded replay of 100 tickets as its stand-in. Ask what changed first asks what changed when a case flips.

      Read a change per step, not as one mean. A tier change can move the mean from 96% to 95% while the review step falls from 94% to 81%. That is a breach on review, and the smaller tier ships for classify only. Read p95 and failing slices too.

      When the SLA lets either latency or cost win, state the trade-off and let the owner choose. A change 40% faster that doubles the bill passes both limits, and only the owner knows what a second is worth. Record the baseline first, then show value as money per ticket against the target.

      1. A change cuts the support agent's cost per ticket by 22% and accuracy falls 3 points. The team looks at both numbers after the run and decides that a 3 point drop is acceptable. Next quarter they ask why the decision process let a loss through. What should the team do differently before the next experiment?

      1. AAsk a second reviewer to approve the 3 point drop once the result arrives, and log the approval.
      2. BWrite the ship threshold and the accuracy guard down and save them before the run.
      3. CLower the saving needed to ship, so that more changes pass the review.
      4. DReport cost and accuracy on one chart, so the trade-off is easier to see for the whole team.
      Show the answer

      Answer: B

      • A A second reviewer who sees the result still chooses the rule after it. Any result can be defended once it is known.
      • B Correct. A threshold and guard metrics saved before the run cannot be bent to fit the result. The same drop is held back or shipped by a rule nobody tuned.
      • C A lower bar makes it easier for a lever to ship. The problem was that the bar moved after the result, not its height.
      • D A chart shows both numbers and still leaves the decision to the room. The limit must exist before the chart does.

      2. A team runs a shorter-prompt test on live traffic and checks the gap every morning. On day 6 the new prompt is ahead by 2 points, so they stop and ship it. The sample grew each day and nobody wrote down when the test would end. What would have made this decision sound?

      1. AChecking the gap twice a day, so a real lead is noticed sooner and the test can stop.
      2. BRunning the test for a fixed week and shipping on the first day that the gap exceeds 1 point.
      3. CKeeping the test running while the gap stays under 3 points, then shipping when it is wider.
      4. DFixing the sample size and the rule first, and reading the result once at the end.
      Show the answer

      Answer: D

      • A More looks give more chances to catch a lead that is pure noise. The team would stop even sooner on a false win.
      • B Shipping on the first good day is still stopping when it looks good. The gap on one day can be noise, and the rule must say when the decision is read.
      • C The team would keep choosing the stopping point from the running result, which is a rule chosen after the fact.
      • D Correct. A sample size and a rule fixed first mean the result is read once, so it cannot be stopped at a lucky moment.

      3. Two prompt variants each answer the same 100 tickets. Variant A gets 91.0 tickets right on average and variant B gets 91.4. The sponsor wants to ship B today because it is ahead, and the pre-registered rule asks for a gain of at least 2 points. What should the team say?

      2. BShip B, because any gain counts when the sponsor has asked for one and B is ahead.
      3. CShip B and watch its accuracy for a month, since a test this small is too small to hurt.
      4. DRe-run the test on the first 50 tickets, where B looks stronger, and report that result.
      Show the answer

      Answer: A

      • A Correct. On 100 tickets one ticket is one point, so 0.4 points is less than one ticket. It is noise and it misses the 2 point rule.
      • B A gain that the sample cannot show is not a gain. The rule asked for 2 points and the gap is 0.4.
      • C Shipping first and watching later skips the check the rule exists for, and puts the change in front of customers.
      • D Choosing the half of the tickets where B looks best is choosing the data after the result.
